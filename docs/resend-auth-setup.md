# راه‌اندازی ورود بدون رمز با Resend

این پروژه ورود و ثبت‌نام را با یک جریان مشترک انجام می‌دهد: کاربر شماره موبایل و ایمیل را وارد می‌کند، کد شش‌رقمی به ایمیل ارسال می‌شود و پس از تأیید، در صورت ناقص بودن اطلاعات به تکمیل پروفایل هدایت می‌شود.

## پیش‌نیازهای Resend

1. در Resend یک API key بسازید.
2. دامنه ارسال را در Resend اضافه و رکوردهای SPF و DKIM آن را تأیید کنید.
3. فایل `.env.resend.example` را مبنا قرار دهید و مقادیر را در فایل محیطی واقعی یا secretهای محیط استقرار تنظیم کنید.
4. `RESEND_FROM_EMAIL` باید متعلق به دامنه تأییدشده باشد.

دامنه آزمایشی `resend.dev` فقط برای ارسال به ایمیل مالک حساب Resend مناسب است و برای ورود کاربران واقعی کافی نیست.

## دیتابیس و اجرا

پس از تنظیم متغیرها، مهاجرت و Prisma Client را به‌روز کنید:

```bash
npx prisma migrate deploy
npx prisma generate
```

کدها پنج دقیقه اعتبار دارند، فقط هش آن‌ها در دیتابیس ذخیره می‌شود، پس از پنج تلاش ناموفق باطل می‌شوند و ارسال مجدد ۶۰ ثانیه زمان انتظار دارد. متغیر `AUTH_OTP_EXPOSE_CODE` فقط برای توسعه محلی است و در production باید خاموش بماند.
